# パスキーログイン

ログインはパスキー（WebAuthn）だけです。`@simplewebauthn/server`と`@simplewebauthn/browser`を使い、Worker（`worker/passkeys.ts`）がチャレンジを1回限り・5分で発行して検証します。RP IDはページのホスト名です。

- ログイン: 端末のパスキーを選ぶだけ（アカウント名は送らない）。
- 新規登録: 名前だけでパスキーを作り、アカウントを作る。メールアドレスは持たない（`users.email`には`@`を含まない仮の値を入れ、APIは空文字で返す）。
- 追加: 設定の「パスキーを追加」で別の端末のパスキーを足せる。最後の1つは削除できない。

成功するとD1へSHA-256ハッシュを保存する256 bitランダムセッションを発行します。以前のGoogleログインで作ったアカウントもIDはそのままで、パスキーを足して移行済みです。

ブラウザのセッション保存キー`tabi.session`を維持し、旧sessionStorageからlocalStorageへも引き継ぎます。期限付きの`tabi.offline-user`はオフライン閲覧のみに使い、サーバーは毎回認証・旅行ごとの権限を検証します。ネットワーク障害ではログアウトせず、401/403では認証を解除します。

招待URLの`invite`パラメーターはログイン中も保持され、参加ボタンで明示的に受諾します。招待は1回限り、7日間有効です。
